# Song Builder

**Song Builder** assembles progressions into a song form. It is separate from editing one chord progression.

## Create an arrangement

1. Start with a custom, suggested, or saved progression.
2. Choose a song-section type: **Intro**, **Verse**, **Chorus**, **Bridge**, **Break**, **Interlude**, or **Outro**.
3. Select **Add Section to Song**.
4. Give the song set a descriptive title and edit each section's own title.
5. Add more sections, including repeated Verse or Chorus sections where useful.

## Reorder sections

Move sections into playback/order-of-performance sequence. For example:

**Intro → Verse → Chorus → Verse → Bridge → Chorus → Outro**

Reordering changes arrangement order, not the chords inside a section.

## Edit versus duplicate

A section's *type* (for example, Verse) and its *custom title* are different. Loading a section into Custom Progression lets you review its chords; use the app's available save/update controls deliberately to avoid unintentional duplicates.

## Full Song view and export

Use the full-song chart to inspect sections in sequence. Exported song packs contain the song summary and instrument-specific charts; longer piano chart sections may continue onto additional pages.

## Save and reopen

Save the song set before leaving. Local saved songs are intended for reuse on the device; verify your backups and exports before deleting app data or migrating devices.
