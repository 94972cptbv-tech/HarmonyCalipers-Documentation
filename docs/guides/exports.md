# Exporting Images and PDF Song Packs

Harmony Calipers can create shareable progression cards, instrument progression sheets, full-song charts, and PDF song packs. Available actions depend on the active progression, song, and instrument.

## Choose an export

| Export | What it contains |
| --- | --- |
| Progression Card | Chords, Roman numerals, key/mode, and harmonic analysis |
| Instrument Sheet | Chord diagrams for a selected progression and instrument |
| Full Song Chart | Song sections in arrangement order |
| Full Song + Chord Charts | Song overview and section instrument charts |
| PDF Song Pack | A printable multi-page document combining sections and charts |

## Modern and Traditional

**Modern** retains the Harmony Calipers visual style. **Traditional** uses a more print-oriented chart presentation. Diagram rendering follows the selected instrument; a Piano export must never silently substitute a fretted diagram.

## Piano chart modes

Choose **Keyboard**, **Staff**, or **Both** in Piano Instrument View before exporting, where supported. The export should preserve the selected mode. The staff representation is not a melody: the bass and treble notes form one chord event.

For larger charts, especially **Both**, the exporter may create continuation pages. Four chords may become two pages of two chords each, rather than a clipped single page.

## Check the result

Before sharing a chart:

1. Confirm the selected instrument and key.
2. Verify all chord names and Roman numerals.
3. Review the diagrams, accidentals, ledger lines, and string labels.
4. Make sure later chords appear on continuation pages.
5. Save or share using the platform share sheet.

## Troubleshooting exports

If the preview shows the wrong chart type, return to Instrument View and confirm the selected instrument and Piano display mode. If a PDF seems incomplete, inspect its later pages. For persistent issues, see [Troubleshooting](../troubleshooting.md).
