# Release Notes

This page documents publicly released versions of Harmony Calipers.

## Version 1.1 — September 2026

### Piano notation and export improvements

Version 1.1 introduced:

- Piano **Keyboard**, **Staff**, and **Both** views for chord voicings
- Corrected chord stacking, accidentals, notehead positioning, and bass ledger clearance
- Piano export modes, with multi-page continuation for taller **Both** charts
- Navigation/picker stability improvements on iPhone and iPad



## Version 1.0 — July 2026

### Initial release

The initial product included the Harmony Wheel, progression editing, Song Builder, instrument chord charts, and image/PDF export.



## Future work

Future enhancements such as full-song transposition, capo support, alternate voicings, and voice-leading assistance are planned backlog items, **not current product capabilities**.
