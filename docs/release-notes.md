## Version 1.1 — Piano notation and export improvements

The 1.1 release work described in the product history includes:

- Piano **Keyboard**, **Staff**, and **Both** views for chord voicings
- Corrected chord stacking, accidentals, notehead positioning, and bass ledger clearance
- Piano export modes, with multi-page continuation for taller **Both** charts
- Navigation/picker stability improvements on iPhone and iPad
