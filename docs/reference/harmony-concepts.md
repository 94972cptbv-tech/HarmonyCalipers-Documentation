# Harmony Concepts and Color Key

Harmony Calipers uses color-coded **progression categories** to describe harmonic character. **Category colors do not identify particular keys, pitch classes, chord qualities, or fixed wedges on the Circle of Fifths.** The labels—not color alone—convey the meaning.

## Harmony category legend

| Visual swatch | Category | Meaning |
| --- | --- | --- |
| <span class="hc-color-swatch hc-functional" aria-label="Blue color swatch"></span> Blue | **Functional** | Conventional tonic/predominant/dominant motion, such as ii–V–I |
| <span class="hc-color-swatch hc-diatonic" aria-label="Green color swatch"></span> Green | **Diatonic / Stable** | Mostly within the selected key, such as I–V–vi–IV |
| <span class="hc-color-swatch hc-dominant" aria-label="Orange color swatch"></span> Orange | **Dominant / Tension** | Dominants, secondary dominants, and turnarounds |
| <span class="hc-color-swatch hc-caliper" aria-label="Purple color swatch"></span> Purple | **Caliper-derived** | Wheel relationships, modal color, or geometric harmony suggestions |
| <span class="hc-color-swatch hc-review" aria-label="Amber/gold color swatch"></span> Amber | **Needs Review** | Ambiguous or experimental function that merits closer attention |

!!! note "Understanding the Harmony Colors"
    Harmony Calipers uses colors to help you quickly recognize different types of harmonic relationships. Each color represents a progression category, not a specific note, chord, or key. The colors of the Harmony Wheel itself serve a different visual purpose.

    Use the category labels and highlighted chord relationships to understand how each progression works.

## See the relationships on the Harmony Wheel

Each diagram is a **documentation illustration**, not an application screenshot. It uses the actual Circle of Fifths order with outer major keys and inner relative minors. The highlighted **path**, rather than the wedge color, demonstrates the musical idea. Step numbers describe a chord's position in the progression; they do not assign permanent meanings to wheel wedges.

### Blue — Functional

**Dm7 → G7 → Cmaj7** in C major is **ii7 → V7 → Imaj7**. Dm7 is on the *minor inner ring*, at the position of F major (its relative-major pairing); G7 and Cmaj7 use G and C on the major ring.

### Green — Diatonic / Stable

**C → G → Am → F** is **I → V → vi → IV** in C major. Am is on the *relative-minor inner ring* inside C, not the A-major wedge.

### Orange — Dominant / Tension

**Cmaj7 → A7 → Dm7 → G7** is **Imaj7 → VI7 → ii7 → V7** in C major. A7 acts as a secondary dominant resolving toward Dm7.

### Purple — Caliper-derived

**C → E → A♭ → C** traces major-third root movement. It is an example of **geometric/symmetry-inspired harmony**, not a conventional ii–V–I. These are root positions; use the app's current suggestion and validation for the exact chord qualities.

### Amber — Needs Review

Some chord progressions don't fit neatly into a conventional harmonic pattern. They may combine different harmonic functions, use unexpected chord relationships, or contain chords that need closer examination.

When Harmony Calipers displays **Needs Review**, it invites you to examine the progression more closely.

This doesn't necessarily mean the progression is musically wrong. Some of the most interesting musical ideas come from exploring unexpected harmonic relationships.

Use the chord analysis and Harmony Wheel to investigate how the chords relate to one another.

*The question mark on the wheel represents a progression that deserves further exploration, rather than a specific harmonic relationship.*

## Roman numerals versus wheel distance

Roman numerals express **harmonic function relative to the selected key**. The wheel/caliper span is a **visual relationship measurement**. They are not interchangeable.

Example in C major:

- Dm7 → G7 → Cmaj7 = **ii7 → V7 → Imaj7**, a functional cadence.
- C → F → Fm → C = **I → IV → iv → I**, using borrowed minor iv.
- A symmetrical thirds cycle may create useful musical color without functioning as a textbook ii–V–I.

## Terms

**Tonal center:** the perceived home pitch/chord of a passage.

**Borrowed chord:** a chord brought in from a parallel mode, such as Fm in C major.

**Voice leading:** the motion of individual chord tones from one harmony to another.

**Caliper-derived:** a Harmony Calipers suggestion based on selected wheel targets or geometric harmonic relationships, not a promise of a traditional cadence.
